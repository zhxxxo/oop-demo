OOP Demo

A small Spring Boot application that demonstrates classes, inheritance, polymorphism and a REST endpoint, served together with static HTML pages.

View students → Raw JSON

Encapsulation

Student keeps its fields private and exposes them through getters only, so the state cannot be changed by accident from outside.

Inheritance

GraduateStudent extends Student and adds a thesis topic on top of the inherited state.

Polymorphism

getLevel() and describe() are overridden, so one list of Student references prints two different formats.

Layered design

Controller → Service → Model. Each layer talks only to the one below it, which keeps the code easy to test and extend.
